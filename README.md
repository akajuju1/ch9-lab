# Chapter 9 Lab — Interactive Shields
Open index.html in a browser. Hover over a service card to see translateY and scale with a smooth transition. The Security Status indicator pulses continuously. Reduced motion preferences are respected. Status text is a demonstration, not live monitoring.

Requirements: custom @keyframes security-pulse; explicit animation-name, animation-duration and animation-iteration-count; transition properties; hover transforms using translateY and scale.

To publish: create a GitHub repository, upload index.html and style.css, then enable GitHub Pages in Settings > Pages using the main branch and root folder. Submit the resulting Pages URL and repository URL.
